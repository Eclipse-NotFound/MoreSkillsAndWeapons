# 非致命激光枪：设计讨论

状态：2026-09-20，game-brainstorming + grilling 进行中。只记录用户选择和源码调查，尚未确认整份方案、未实现或部署。当前已有智能武器 HUD / 弹道等并行工作，本设计不修改或接管它们。

## 用户原始设想

新增单发非致命激光枪：命中敌人眼部致盲，失明期间敌人无法发现玩家，惊慌并四处胡乱攻击。准星靠近敌人提供辅助瞄准，高速移动时辅助变差。

## 已确认选择

| 题号 | 选择 | 用户决定 |
|---|---|---|
| Q1 | A | 精瞄控场：让关键敌人失控、打乱战局。 |
| Q2 | A | 激光自身零生命伤害；诱发的恐慌攻击仍造成真实伤害，可以间接致死。 |
| Q3 | A | 半自动点射，一次点击一发，松开后可再次点射；不是一发一装或蓄力。 |
| Q4 | A | 暂时失明，到时恢复。 |
| Q5 | B | 开火瞬间，在小角度内将光束方向修正至眼部；未选择枪口缓慢吸附或鼠标准星吸附。 |
| Q6 | A | 按玩家实际移动速度削弱辅助，包含水平与垂直移动。 |
| Q7 | B | 基础致盲 6 秒，作为可在设置调整的初始值。 |
| Q8 | A | 再次有效命中刷新为基础时长，不累加；持续精确射击可维持控制。 |
| Q9 | A | 惊慌时小范围乱走、间歇随机攻击，停止追踪玩家实时位置；随机攻击仍可能碰巧命中玩家。 |
| Q10 | A | 移动速度越高，可自动修正的角度越小，最终归零；不增加散布或额外失效概率，手动精瞄仍有效。 |
| Q11 | A | 眼部小容差区，要求从正面或斜前方射入，背后不能直接致盲。 |
| Q12 | B | 有眼生物，以及机器人、炮塔的视觉传感器。不同类型需分别适配，不能仅因普通枪手原型通过就声称全敌人支持。 |
| Q13 | A | 恐慌攻击允许误伤同阵营及中立单位；射手自身阵营不变。 |
| Q14 | A | 取消这把枪的普通隐藏命中抽签，以有效眼区几何命中为准；墙体、射入方向、明确防护仍适用。 |
| Q15 | B | 首领与普通敌人同样完整失明 6 秒，可再次命中刷新，不单独缩短或免疫。 |

## 待回答与设计树

当前一轮尚待 Q16（恢复后重新感知还是继续原目标）、Q17（行动时间或现实时间）和 Q18（射击节奏/耗能）。已回答的问题不重复询问。

下游仍需收敛：特殊防护、辅助半径/角度/视线与目标选择、SATS处理、获取方式与反馈。机器的“失明”表现为感知故障：可移动机器人乱走乱射，固定炮塔原地乱转乱射，保留其移动能力边界。次要参数可提出一套明确初值供用户整体确认，不把建议写成已授权实现。

实现前首个最小验证应只选普通持枪 Raider：暂停原控制后玩家换位是否仍改变其瞄准；独立随机移动/射击是否正常；恢复控制是否正确；若采用友伤，验证只影响恐慌期发出的攻击。成功后再扩展近战生物、机器和炮塔。此验证尚未执行，完整范围尚不能承诺已可用。

扩展范围的静态风险已核对：UnitAIRobot 无 controlOn，stun 分支不会直接停止控制，且 actPort 另有直接读取玩家位置的路径；UnitTurret 的停止标志 sleep 为 internal，公开 hack(0) 有额外状态副作用，不能直接当可恢复的临时关 AI；Zombie/Hellhound 也无 Raider 的控制开关，stun 后仍有后续感知或近战流程。证据：unit/UnitAIRobot.as:161、246、498；UnitTurret.as:21、385–413、572、648、737；UnitZombie.as:561；UnitHellhound.as:116、169、540。完整支持是已选目标，不能把这些差异默认为已解决；先验证本模组内可行接入点，若最终必须修改游戏本体，再据具体改动取得相应授权。

首领按用户 Q15 与普通目标同规则，不依赖一个可能不完整的“首领分类名单”来施加特殊抵抗。

不要通过临时改变敌人阵营实现友伤，既有子弹引用射手对象，会波及其他攻击。临时控制必须记录原状态并安全恢复，不能唤醒本来禁用/剧情控制的单位。

## 后续原型应回答的问题（未执行）

1. 单位正面/背面、眼区/身体、墙后/无遮挡的命中是否符合规则；生命值始终不变，眼部有效命中不受普通命中抽签影响。
2. 玩家在失明期间走动、开火或绕到背后，敌人是否仍仅按自身状态和随机数行动，完全没有实时追踪；原本正在追击的敌人也必须通过。
3. 恐慌移动、枪口转向、原武器射速/装填是否仍正常；近战、移动机器与固定炮塔分别验证，首领同样纳入最终范围。
4. 同阵营/中立误伤仅由恐慌期发出的攻击触发；入盲之前的在途攻击不被追溯改变；失明结束后已发出的攻击保留其发射时语义。
5. 刷新不叠加，恢复不丢失已有眩晕/冻结/剧情禁用状态；死亡、换房、读档和关闭功能时清理临时状态且不残留禁用 AI。
6. 辅助只影响本武器该次开火；移动变快时角度范围缩小，纯手动精确命中不失效。验证与现有智能武器、跳弹、SATS、Sandevistan 的边界，不能把旧版测试当本武器已经通过。
