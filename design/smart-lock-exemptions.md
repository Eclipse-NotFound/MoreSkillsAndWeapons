# 智能武器锁定豁免

2026-09-23 用户选择第一批范围：生物（其他生物加肉食灵）、云团与巢穴、小型机械、普通地雷、机关与装置。后续回答明确普通地雷6项、机关与装置8项分别勾选。

## 设置与范围

| 设置页 | 独立选项 |
|---|---|
| 生物 | 血翼、鱼类、辐射蟑螂、老鼠、鼹鼠、辐射蝎、蚂蚁、史莱姆、肉食灵 |
| 云团与巢穴 | 死灵云团、肉食灵巢穴、蚁穴 |
| 小型机械 | 机械精灵、旋翼机、电击球、蜘蛛地雷、无马机 |
| 普通地雷 | 土制、破片、等离子、脉冲、斑马破片、野火地雷 |
| 机关与装置 | 瓶罐警铃、绊线、压力板、激光传感器、陷阱枪、蹄雷串、部署好的炸药、发报机 |

共31个复选框，默认全部不勾选；勾选含义为“不锁定”。基础类别涵盖所有对应变种；肉食灵包括肉食灵王，巢穴独立。无马机只含常规三型，不纳入雷霆之首部件。本批不加小马阵营、大型机械、炮塔、其他首领、训练假马、伙伴或特殊战斗部件。

Pip 模组菜单增加五个独立设置页；F6 浮层共八页，Tab/PageDown向后、PageUp向前，无新增热键。每页恢复默认只清除本页选项。配置由本模组保存，旧配置空表表示维持原行为。

## 生效规则

- 单目标、多重锁定共用同一张表，在原阵营、存活、房间、NPC等资格检查之后收窄范围，不把原本不可锁定的目标变为敌人。
- 开启某项后，下一次智能武器更新即清除该类候选/已完成锁定及标记；其他类别的进度保持。
- 已发射子弹在下一次物理推进停止追踪豁免目标，不改投其他目标；普通碰撞和伤害保持。
- 取消豁免后必须重新获取；已停止追踪的子弹不恢复制导。
- 时停回放仍按原记录顺序消费；原目标现已豁免的记录不恢复制导，也不挤占后续子弹的目标。

## 实现边界

`MSWSmartExclusions` 集中管理精确实体ID、显示名、页面与配置清洗；不按生成别名、阵营或共用AI类粗分。ID证据见 `../knowledge/discoveries/smart-lock-exemption-catalog-20260923.md`。分类不等同于无敌/禁伤，开关不影响原生伤害与敌人AI。
