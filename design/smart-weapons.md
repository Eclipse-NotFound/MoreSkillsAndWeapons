## 用户目标

为子弹类武器增加目视与准星停留锁定、飞行中转弯、绕障追击，以及失去目视后的渐进脱锁。《赛博朋克 2077》智能武器是用户指定的灵感来源；本设计的具体规则以用户选择为准，不声称复刻该游戏的全部细节。

## 已确认选择

| 题号 | 用户选择 | 规则 |
| --- | --- | --- |
| Q1 | B | 自动尝试绕过附近简单障碍，例如箱体、低墙或简单拐角；复杂多拐角寻路不在本轮已定范围内。 |
| Q2 | A | 玩家看见敌人即可锁定，不要求敌人发现玩家。 |
| Q3 | 先做 A | 初版单目标锁定。 |
| Q4 | A | 基本目视：敌人在屏幕内、无墙体遮挡、非隐形；不受黑暗和玩家朝向限制。 |
| Q5 | A | 敌人仍可见时，准星移开也保持完整锁定；准星在另一名敌人附近停留并完成锁定后才切换目标。 |
| Q6 | A | 已锁定敌人被遮挡后，在脱锁完成前仍可追踪其当前位置；不能隔墙首次获取锁定。 |

| Q8 | A | 发射后独立追踪：每颗子弹记住发射时的目标与制导强度；之后玩家失去目视或改锁其他目标，不影响这颗子弹。武器脱锁衰减影响后续发射。 |
| Q9 | B | 再次看见尚未完全脱锁的敌人时，自动逐渐恢复强度，无需重新把准星移过去；完全脱锁后须按准星停留重新获取。 |
| Q10 | B | 允许大幅转弯乃至掉头，但转弯有速度上限，不能瞬间折角。具体转弯数值待最终确认。 |
| Q11 | A | 跳弹后继续追踪原目标：先按墙面反射，再逐渐转向；既有跳弹次数、概率和伤害/速度衰减继续生效。 |
| Q12 | A | 初版覆盖普通实弹枪和霰弹枪，特殊弹药随枪支持；不覆盖激光/等离子等能量枪、喷火器、火箭与榴弹发射器。 |
| Q13 | B | 智能子弹豁免普通命中率抽签，保留护甲、抗性、无敌以及特殊敌人的独立闪避机制。 |
| Q14 | A | 总开关默认关闭；开启后仅玩家使用符合条件的枪械即可锁定，不需要额外装备或技能。 |
| Q15 | A | 支持的枪械之间换枪保留锁定；切到近战或不支持的武器时清除。两种情况下已发射的子弹继续独立追踪。 |
| Q16 | A | 制导时限可调，初值 2 秒；从发射开始累计，整条跳弹链共享且不刷新，到期沿当前方向正常飞行，不延长原弹寿命。 |
| Q17 | A | 首次锁定中断时先短暂容错，然后进度逐渐回退；改瞄另一名敌人从零开始；失去目视时不能继续完成首次锁定。 |
| Q18 | A | 主要参数可调，设置单独放入智能武器页；默认数值作为试调起点，经实测再校准。 |

| Q20 | B | 时停期间玩家仍可操作时，锁定、恢复和脱锁继续计时；子弹制导时限仅实际推进时消耗。菜单等真正暂停全部冻结。 |

Q8 已明确 Q7 的衰减作用于后续发射时的制导强度；每颗已发射子弹保留自己的强度。Q16 的 2 秒是弹丸实际推进时间，按 Q20 与玩家锁定时钟区分，不是时停中的两秒现实等待。

## 已确认初值与调节范围

下列数值已由用户整份确认并实装，全部保留调节入口。机制通过隔离游戏验证；初值仍是可试调的体验起点，不代表已完成长期平衡测试。

| 参数 | 建议初值 | 拟开放范围 |
| --- | --- | --- |
| 准星距目标身体轮廓的锁定容差 | 48 场景像素 | 0–200，步长 4 |
| 首次锁定时间 | 0.6 秒 | 0.1–3 秒，步长 0.1 |
| 首次锁定中断容错时间 | 0.15 秒 | 0–0.5 秒，步长 0.05 |
| 首次锁定进度从满值退至零所需时间 | 0.6 秒 | 0.1–3 秒，步长 0.1 |
| 失去目视后的保持时间 | 0.6 秒 | 0–3 秒，步长 0.1 |
| 视野外保持锁定 | 关闭 | 开 / 关；开启时已完成锁定跳过保持及衰减计时 |
| 锁定强度从满值衰减至零所需时间 | 1.5 秒 | 0.1–5 秒，步长 0.1 |
| 重新目视后从零强度恢复至满值所需时间 | 0.4 秒 | 0.1–3 秒，步长 0.1 |
| 满强度基础转向速度 | 1080 度/游戏秒 | 90–2880，步长 90 |
| 转弯半径倍率（越小越急） | 50% | 10–200%，步长 10 |
| 每条弹链制导时限 | 2 秒（已选） | 0.1–5 秒，步长 0.1 |
| 锁定菱形屏幕宽高 | 24 px | 12–80 px，步长 2 |

锁定进度、强度衰减和恢复初版建议线性变化。已有部分强度时按同一速率恢复；重新短暂看见后又失去目视，保持的是当时的强度，不凭一次露头直接回满。转向速度乘以出膛时强度；初版不额外提高弹速、伤害，也不增加耗弹或资源成本。

半径倍率同时调整平滑追踪曲率与角速度上限，避免只提高上限却被平滑公式抵消。实际角速度上限为基础转速 × 出膛强度 ÷（倍率/100）；实际路径仍由目标相对位置、弹速、障碍与转弯上限决定，并非固定半径的圆。倍率随发射取快照，跳弹和时停回放沿用；HUD 大小即时读配置，不影响锁定距离或碰撞。

## 已确认边界与表现

- 仅接管本地玩家的新发射合格弹丸；首次锁定完成前发出的普通子弹，不因之后取得锁定而补上制导。霰弹的各颗弹粒共享本次目标、各自飞行和碰撞，不取消原散布。
- 候选只取当前敌对、存活且可攻击的单位，排除队友、宠物与中立 NPC；持续复查阵营，目标被黑入/转为友方后立即停止追踪。初次获取的可见性筛选与既有锁定的保持阶段分开，不能因遮挡马上删除已锁定目标。
- 多名候选靠近准星时按身体轮廓距准星最近选取，距离相同时保持当前候选以避免抖动。获得新锁定前仍保留旧目标；切换完成只影响之后的新弹丸。
- 目标身体至少有一处在屏幕内、非隐形且地形视线可达时可建立目视；离屏或隐形按失去目视进入保持/衰减。初版不增加屏幕外箭头，屏幕内已锁目标的框持续显示到完全脱锁。
- 绕障仅尝试有限的局部路线，转弯速度和实体碰撞照常约束运动；找不到路线时继续物理飞行和正常碰撞/跳弹，不悬停、不穿墙、不保证封闭空间命中。不主动为命中规划跳弹路线，但发生跳弹后可继续转向追踪。
- 目标死亡、离开当前地点或对象失效时，该目标相关锁定清除，已有子弹停止追踪并继续物理飞行，不自动寻找新敌人。子弹最终何时消失仍由原寿命、碰撞、越界等决定。
- 取得智能制导的子弹在原寿命及其跳弹续弹期间保留普通命中抽签豁免，制导到期只停止转向；特殊敌人防御仍保留。此细化随 Q21 一并确认。
- 弹丸目标、强度、转向能力及制导总预算在发射时取快照，跳弹继承剩余预算；修改设置不追溯加强在途弹丸。关闭总开关立即清除当前锁定并停止所有转向，不删除已发射子弹，其已取得的普通命中抽签豁免保留到弹链终止。
- 换房、读档或玩家死亡清空临时锁定/追踪对象；锁定目标不写入存档。进入 SATS 时清除当前锁定，让 SATS 新发射弹丸沿用其自身目标规则；已发射智能弹仍依自身制导预算处理。
- 目标上红蓝空心菱形沿边缘表达获取、已锁和脱锁，顶部起逆时针覆盖；大小可调，旧文字条已由 v1.5.3 替换。Pip 模组菜单与 F6 浮层共用智能参数定义，并提供页切换，不新增全局热键。

上述边界随用户最终实装指令确认。入口为 Pip「模组 → 智能武器」；游戏中 F6 打开浮层，Tab/PageUp/PageDown 切页、方向键调整。单页恢复默认不重置原有跳弹配置。

## 实装结构与验收

1. `MSWSmartLock` 管理获取、保持、衰减、恢复；每颗弹丸独立保存目标、强度、转速和剩余时间。
2. `MSWSmartStep` 继承宿主 `fe.Pt`，位于场景链首，在玩家开火后、子弹首步前制导。编译期外部存根不嵌入 SWF；无本体补丁。
3. `MSWSmartRoute` 做 24 px 网格、240 px 局部范围、最多 180 扩展节点的有限寻路；每次物理推进最多 4 次搜索，相近弹丸共享本步路线，未轮到的下一步重试。真实 Bullet 保留原速度、逐步碰撞和伤害流程。
4. Sandevistan 普通时停沿实际 `loc.step` 消耗预算；回放期临时新类 `fe.weapon.MSWSmartReplayStep` 接入其原有玩家弹丸循环，按武器/出生位置/顺序为重建弹丸找回发射快照。回放中仅按录像钉住的旧弹不重复扣时。此适配依赖当前 Sandevistan 的回放协议。
5. 42 项纯规则、真实游戏首步/绕箱命中/跳弹/霰弹特殊弹药/设置/锁定流程、Sandevistan 联合运行通过；既有 315 项跳弹及真实设置/伤害回归通过。覆盖条件及保留边界见实验记录。
6. 已备份 v1.4.1 并安装生产 SWF，正式同字节隔离重启通过，版本 `1.5.0-smart-weapons`、frames=900、设置入口响应。游戏本体、其他模组源码和真实存档未修改。

## 实现前的工程调查记录

以下保留实现前的源码调查及当时待验风险；现状以以上实装结构与实验记录为准，不能将历史“尚未实现”视为当前停点。

- 静态源码：普通 Bullet 暴露速度方向，可在飞行中改变方向；原版 SmartBullet 追踪目标，但没有绕障寻路。
- Location.isLine 可辅助检查地形遮挡；Unit.isVis 不等同于玩家当前实际目视状态。
- 既有跳弹续弹会创建新的 Bullet 对象，需要为制导状态定义继承规则。
- 武器范围静态证据：普通实弹枪与霰弹可按武器来源 `skill=2、tip=2/3` 辨认；特殊等离子弹会改变弹丸伤害类型，故不能只查 `tipDamage==0`。激光、喷火、火箭/榴弹炮弹也可能使用 Bullet 类。参考 `game-reference/decompiled/1.02/src102/scripts/fe/weapon/Weapon.as:1462、1685` 与 `fe/AllData.as:3013、3795`。Q12 已选择按枪种限定。
- 命中率静态证据：`fe/unit/Unit.as:4072` 在身体碰撞后再抽签；普通 `tipBullet==0` 子弹设 `miss=0、precision=0` 可豁免这层，仍走原伤害、护甲、抗性等流程。无人机等另有特殊闪避/免疫，不应顺带取消；也不应为追踪直接填写 `targetObj`，否则会改变特殊判定及沿途敌人碰撞（`fe/weapon/Bullet.as:505`）。Q13 已选择豁免普通抽签，尚待实现验证。
- 模组扫描在世界更新之后，贴脸或贴墙发射可能在首次接管前已经碰撞；未验证能覆盖所有出膛当帧情况。
- `Bullet` 速度按像素/游戏步，默认寿命 100 步；`World.fps=30` 为源码名义值，约 3.33 游戏秒。不能因设置更长制导时间而延长原弹寿命，也不能把显示帧直接等同弹丸实际步数（`fe/weapon/Bullet.as:27、193、240、411`；`fe/World.as:44`）。
- `MSWU.inGameplay` 放行 `onPause && !godMode`，不能单独用它判断子弹是否实际推进。锁定与弹丸预算须各自选对时钟。
- 聚合菜单 `registerPage` 支持同一模组注册独立页，每页当前上限 18 项；F6 仍读取固定的 `buildMswItems()`，需增加页切换接入而非只注册聚合页（`MSWSettingsHub.as:25`、`MSWPipTab.as:847`、`MSWPanel.as:30、115`）。
- Sandevistan 最小只读核查：时停设置世界暂停但逐显示帧推进玩家，玩家子弹按节流后的 `loc.step` 推进；临时把弹丸伤害归零并在其内部保存原值，所以不能以当前 `damage>0` 作为智能弹存活/资格条件，也不能擅自恢复伤害。普通时停未发现对 Bullet 速度的缓存回写；回放会重建部分玩家弹丸，引用快照不能自然跨过换体。这些是静态风险，尚未经联合运行验证。
- 时停兼容补充证据：`SandevistanMod.as:3195、4628、4700` 对应伤害归零和节流步进；`:1755、2120` 对应回放换体/录像位置约束。`sandyActive/replaying/origDam` 是私有状态，不能直接读取。用 `onPause && godMode` 排除回放会与玩家原本开启无敌的情况混淆，必须列为已知未验边界；不能宣称已可靠识别全部时停状态。
- 实际子弹步数可结合普通活弹 `liv` 下降和 `dist/X/Y` 变化观察，但碰撞把寿命改为 4、跳弹/回放换体会重置寿命，不能把任意寿命差直接当推进步数。
- 敌对筛选静态依据：`Unit.as:78、4522、4799`、`UnitPet.as:61、387`。`isMeet` 不含敌我判定；玩家/宠物为阵营 100，阵营 0 含中立/特殊对象，初版可从 1–4 的有效可攻击对象筛选并排除 `npc/noAgro/disabled/trigDis`。阵营变化与特殊单位需验证，不能把临时不可见直接用于清除保持中的目标。
- 以上是实现可行性调查，尚未构建或运行智能武器原型，不能作为绕障成功率或性能保证。
