# 多次跳弹与额外跳弹衰减（v1.4.0）

|---|---|---|---|
| ricochetCount | 基础跳弹次数 | 0–20 / 1 | 1 |
| ricochetChance | 额外跳弹概率 | 0–100% / 1% | 0% |
| ricochetChanceDecay | 额外概率衰减 | 0–100% / 1% | 0% |
| ricochetDamageDecay | 额外伤害衰减 | 0–100% / 1% | 0% |
| ricochetSpeedDecay | 额外速度衰减 | 0–100% / 1% | 0% |

## 规则

1. 基础次数内，符合原跳弹条件的墙撞必定反弹，不减伤、不减速。基础次数为零时，首次撞墙即进入额外阶段。
2. 第 k 次额外反弹的**条件概率**为 `P × (1 - 概率衰减/100)^(k-1)`，其中 P 为首次额外概率。不是整条链达到第 k 次的累计概率。每次碰撞独立抽取；失败即沿原流程消亡。
3. 每次成功额外反弹后，新弹伤害和速度分别乘以 `1 - 对应衰减/100`。例：基础 3 次、额外概率 80%、概率衰减 50%，第 4/5/6 次反弹的条件概率为 80%/40%/20%；伤害衰减 20% 时额外飞行段伤害依次为原伤害的 80%/64%/51.2%。
4. 单颗原始子弹整条链最多成功反弹 100 次；当前或衰减后的伤害不大于零、速度小于 1 像素/游戏逻辑步时终止，不生成零伤害或近乎静止的续弹。每段寿命沿用原实现的 100 个游戏步，不换算固定秒数。
5. 每颗子弹首次被模组帧扫描登记时，快照全部跳弹设置；续弹继承同一快照与计数。实现没有拦截原版发射函数，因此采样时点是发射当帧的首次扫描，不承诺两个时点之间的亚帧级设置切换。关闭时已飞行的子弹也登记为不跳弹，后续开启不追溯生效。
6. 范围仍为玩家普通枪弹，原有非爆炸/非火焰减速弹分类保持。打碎墙不反弹，命中单位原本应消亡的仍消亡；穿透弹反弹回来允许再次伤害同一目标。不新增敌人跳弹、不改榴弹炮 wallHits / bounce 物理。

## 实现与回归重点

- MSWRicochet 持有快照、次数和下一次概率；plan 只计算续弹参数，生成 Bullet 成功后才 recordBounce。反射面与位置用入射速度计算，伤害/速度衰减只作用于新段。
- MSWBullets 保留既有帧后重生方式。新增 ricBounce / ricExtra / ricStop / ricLastCount 诊断。
- 修复一处旧边界：出生帧即撞墙时，扫描阶段生成的续弹可能被同帧清理分支删除跟踪记录，从而下次重新登记、重置次数。现在将新生成对象标为本轮已见；普通连续链与出生帧碰撞均有回归覆盖。

## 验证与边界

- `build/test-ricochet.ps1`：在游戏自带 AIR 中运行生产规则/追踪代码，使用测试专用 Bullet 对象链替身；266 项断言覆盖概率临界值、100 次上限、基础/额外衰减、首帧碰撞、配置快照、旧存储、新键往返、默认值和 F6 各行。替身只在测试源路径内，不进入生产 SWF。
- `build/test-game-smoke.ps1`：复制当前根目录游戏资源到 build/test-runtime，采用原 pfe.swf 启动入口与独立应用 ID。仅加载本模组测试构建；验证真实 Pip 17 行、五个真实滑块事件、真实恢复默认点击、真实游戏 Bullet 对象连续 3 次基础 + 1 次额外反弹以及随后终止。
- 游戏冒烟用暂停世界、人工设置真实子弹的撞墙状态来获得确定性，**不是自然开火全流程、多人/多模组共存或高弹量性能实测**。原有首次跳弹方向逻辑未改；概率曲线使用确定性随机值测试边界，不拿少量随机样本代替概率验证。
- 运行结果与界面截图位于 build/out/tests/results.txt、build/out/smoke/results.txt、build/out/smoke/settings.png；均可重建，不入 git。测试进程及临时描述符由脚本清理，正式 pfe 存档不写入。
- 生产构建：build/out/MoreSkillsWeaponsMod.swf，诊断版本 `1.4.0-ricochet`。本轮尚未覆盖正式 release 或重打 dist。

## 再次构建

在 build 目录调用 Animate 的 `jre/bin/java.exe` 与 `Common/Configuration/ActionScript 3.0/bin/mxmlc.jar`，传入 `-target-player=11.1`、`-source-path+=../src`、`-output=out/MoreSkillsWeaponsMod.swf`、`../src/MoreSkillsWeaponsMod.as`。PowerShell 中选项整体加引号，尤其包含 `+=` 的参数。本机 Java 17.0.10 与既有 Flex 4.6 编译器已成功组合使用，不依赖 PATH 的 java 命令。
