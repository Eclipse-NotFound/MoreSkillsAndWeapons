# 智能武器锁定菱形

2026-09-20 用户确认，替代旧目标矩形及准星旁的文字/横条。

- 空心正菱形：顶点间宽、高各 40 屏幕像素，2 像素描边。镜头与父层缩放不改变标记尺寸；描边外缘略超出 40 像素路径。
- 中心跟随敌人身体：包围盒中心沿朝向前移身体宽度的 15%，竖直位置在身体高度的 40% 处，靠近前胸。
- 红色 `#FF4040` 为尚未锁定部分，蓝色 `#40A8FF` 从顶部尖角出发，按顶 → 左 → 下 → 右 → 顶逆时针连续覆盖。
- 候选目标读取 `lock.progress`；已锁目标读取 `lock.strength`。满锁仅画完整蓝圈；下降时覆盖终点沿同一路径退回。
- 旧锁与新候选可各有一个标记；新候选完成后沿用原锁定切换规则。两者归零即移除，不另加消失动画。
- 遮挡后仍显示候选/已锁目标，时长完全服从原宽限、回退、保持、衰减规则。显示层不再做一次目视过滤。
- 暂停、菜单、主开关等隐藏条件沿用 `MSWSmartWeapons.frame`；标记不接收鼠标，不新增文字、声音或输入。

实现：`MSWSmartHUD` 只绘图；`MSWSmartWeapons` 传入原 `MSWSmartLock`。尺寸与配色为本轮确认的固定 UI 值，不增加设置项；既有锁定参数设置入口保留。

验证：`build/test-smart-hud.ps1` 检查实际光栅颜色、方向、缩放、跟随和清理；`build/test-smart-hud-game.ps1` 在原游戏副本中生成真实 Raider，检查接入、状态转换并截图。
